# Museu Digital de Mirassol

Site estático demonstrativo do projeto-piloto de extensão no Museu Municipal Jezualdo D’Oliveira.

## Páginas
- index.html
- cabra-de-duas-cabecas.html
- ciclo-do-cafe.html
- fosseis.html

## Publicação no GitHub Pages
Em **Settings → Pages → Build and deployment**, selecione **Deploy from a branch**, branch **main**, pasta **/(root)** e salve.

## Revisão e direitos
- Protótipo: textos não representam posicionamento oficial do museu.
- Validar informações históricas e obter autorização antes de publicar fotos.
- Não incluir CPFs ou dados pessoais de entrevistados.
- Só imprimir QR Codes quando as URLs definitivas estiverem testadas.
